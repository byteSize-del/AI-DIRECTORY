# AI-DIRECTORY

A comprehensive online platform that serves as a directory for various artificial intelligence (AI) tools, resources, and services.

## Project Structure

```

├── index.html              # Main homepage
├── css/                    # Stylesheets
│   ├── index.css
│   ├── about.css
│   ├── services.css
│   ├── contact.css
│   ├── login.css
│   └── update.css
├── pages/                  # Secondary pages
│   ├── about.html
```

## Features

- **Homepage**: Welcome page with quick information about the platform
- **About**: Information about the AI Directory mission and team
- **Services**: Comprehensive list of AI tools including:
  - Google Veo 3
  - ChatGPT
  - MidJourney
  - DALL-E 2
  - DeepL Translator
  - Jasper AI
  - Copy.ai
  - Writerly
  - Rocket AI
- **Updates**: Future implementations and platform roadmap
- **Contact**: Feedback form for users
- **Login**: User authentication page

## How to Use

1. Open `index.html` in your web browser
2. Navigate through different sections using the navigation menu
3. Explore various AI tools in the Services section
4. Contact us through the Contact page for feedback
